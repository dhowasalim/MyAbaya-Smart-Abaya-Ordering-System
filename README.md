# MyAbaya-Smart-Abaya-Ordering-System
A full-stack e-commerce web application developed for an abaya retail store as part of the CIS 311 course project.

## Overview
MyAbaya allows customers to browse, customize, and purchase abayas online through a modern and user-friendly interface.  
The system also includes an admin dashboard for product management.

## Features
- Product browsing and details page
- Shopping cart using PHP sessions
- Checkout system
- Admin authentication
- Add / Edit / Delete products
- Purchase tracking using cookies
- Google Maps integration
- JavaScript form validation
- Responsive web interface

## Technologies Used
- PHP
- PhpMyAdmin
- HTML
- CSS3
- JavaScript
- XAMPP

## Database Features
- Normalized relational database
- Products table
- Admins table
- ER Diagram implementation
- CRUD operations
